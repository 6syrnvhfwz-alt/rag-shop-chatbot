# Day 6 · RAG 智能客服：多轮对话记忆

对应代码：`rag_chatbot_v2.py`

## 今天解决了什么问题

Day 5 的客服"记性只有 7 秒"：

```
客户：退换货运费谁承担？
客服：质量问题店铺承担，非质量问题买家承担。
客户：那尺码不合适算哪种？   ← Day 5 的客服听不懂"哪种"指啥
```

人说话天然带指代（"那""这个""它""这种"），没有上下文就理解不了。

## 核心改动（就两处）

1. **接口换了**：`/api/generate`（单轮，只会发一段话）→ `/api/chat`（多轮，收 messages 数组）
2. **维护 history 列表**：每轮对话把"客户问的 + 客服答的"追加进去，下一轮整包发给 AI

## messages 数组的三种角色

```python
[
  {"role": "system",    "content": "你是客服，只根据资料回答... 【店铺资料】..."},
  {"role": "user",      "content": "退换货运费谁承担？"},      # 客户
  {"role": "assistant", "content": "质量问题店铺承担..."},     # 客服
  {"role": "user",      "content": "那尺码不合适算哪种？"},    # 客户追问
]
```

- **system**：AI 的身份设定 + 本轮检索到的资料（注意：每轮都用最新资料）
- **user**：客户说的话
- **assistant**：AI 自己之前说过的话——AI 看到这些，就知道"哪种"指的是运费责任

## 关键细节

- 历史记录每轮追加两条（user + assistant），AI 才能看到完整来回。
- system 提示词里要写明"客户可能用'那''这个'指代上一轮内容"，提醒它结合上下文。
- 企业做法：历史太长会撑爆上下文窗口，真实项目只保留最近 5-10 轮，更早的总结成摘要。
